# تطبيق المبيعات والتحصيل — MVP

هذه نسخة خفيفة مبنية من ملف **TOTALA2026 - Copy - Copy(2).xlsx**، وتستبدل المعادلات والربط بين الشيتات بقاعدة SQLite وحسابات واضحة داخل التطبيق.

## التشغيل على Windows
1. فك ضغط الحزمة في مجلد عادي.
2. تأكد من وجود Python 3.10 أو أحدث.
3. اضغط مرتين على `run_app.bat`.
4. في أول تشغيل فقط سيتم تثبيت Streamlit إن لم يكن موجودًا، ثم يفتح التطبيق في المتصفح.

## الوظائف الموجودة
- لوحة تحكم بالمبيعات والليترات والتحصيل والرصيد.
- إدخال حركات بيع جديدة.
- إدخال المقبوضات.
- عرض/بحث الزبائن وإضافة زبون.
- عرض المخزون المحسوب وإضافة مادة.
- عمر الدين حتى أي تاريخ تختاره.
- محصلة شهرية حسب المندوب.
- مسارات المندوبين المستوردة من الملف.
- تدقيق مشاكل ملف Excel ونسخ احتياطية SQLite / CSV.

## منطق الحساب
- الليترات = حجم المادة × الكمية.
- إجمالي البيع = CEILING(الكمية × السعر × (1 - نسبة الحسم)).
- الرصيد = الرصيد الافتتاحي + المبيعات - المقبوضات - التسوية/الحسم على الرصيد.
- المخزون = الرصيد الافتتاحي للمادة - مجموع الكميات المباعة.

## قرار مهم بخصوص الملفات الخارجية
ملف Excel الأصلي يحتوي روابط إلى ملفات أخرى (`TOTAL 2020.xlsx` ونسخ Brighton 2025/2026). لم يتم ترحيل القيم الخارجية تلقائيًا كرصيد افتتاحي، لأن الكاش الخارجي قد يحتوي حركات متداخلة مع 2026 ويؤدي إلى **Double Count**. قاعدة التطبيق الحالية تعتمد الحركات الفعلية الموجودة في الملف الحالي، مع حقل مستقل للرصيد الافتتاحي يمكن اعتماده لاحقًا بعد تحديد مصدره الصحيح.

## تحديث قاعدة البيانات من ملف Excel
الملف `import_from_excel.py` يعيد بناء قاعدة جديدة من ملف XLSX دون استخدام Excel أو openpyxl:

```bat
python import_from_excel.py "TOTALA2026 - Copy - Copy(2).xlsx" "data\total_sales.db"
```

يفضل أخذ نسخة احتياطية من `data\total_sales.db` قبل إعادة الاستيراد لأن الأمر يعيد بناء القاعدة.
